## 2026-09-28 - Case Study Accordions & Mobile Drawer Keyboard/A11y Pattern
**Learning:** In raw HTML single-page applications with custom clickable containers (`.case-row`), nested `<button>` elements create invalid interactive control nesting. Converting nested buttons to `<span aria-hidden="true">` and applying `role="button"`, `tabindex="0"`, `aria-expanded`, keyboard event listeners (`Enter`/`Space`), and `:focus-visible` outline provides full WCAG compliance without changing visual design. Additionally, off-screen drawers with `transform: translateX(100%)` require `visibility: hidden` when closed to prevent tab trapping off-screen links.
**Action:** Always check interactive container `div`s for nested `<button>` tags, apply `visibility: hidden` to CSS off-screen drawers, and mirror `:hover` styles in `:focus-visible` focus outlines.
