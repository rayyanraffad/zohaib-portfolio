## 2025-09-25 - Accordion & Mobile Drawer Accessibility in Raw HTML Templates
**Learning:** Raw HTML landing pages with clickable `div` containers and nested `<button>` tags cause nested interactive controls accessibility errors and fail keyboard navigation. Adding `role="button"`, `tabindex="0"`, `aria-expanded`, and converting nested buttons to `<span aria-hidden="true">` restores standard accessibility and prevents accidental collapse when interacting with text inside expanded details. Additionally, mobile drawers using CSS transform must include `visibility: hidden` when closed to keep off-screen links out of the tab order.
**Action:** Always audit raw HTML accordions and navigation drawers for keyboard navigation, tab order, focus rings (`:focus-visible`), and ARIA states.
