## 2026-07-10 - [Accessibility Enhancement for Case Studies]
**Learning:** Interactive elements implemented as `div`s with `onclick` handlers in static HTML files (like `public/site.html`) are not automatically accessible. They require manual addition of `role="button"`, `tabindex="0"`, `aria-expanded`, and unique `aria-label`s, along with a global keyboard listener for 'Enter' and 'Space' keys to ensure parity with native buttons. Nested `<button>` elements within such interactive parents should be avoided or converted to non-interactive `<span>`s with `aria-hidden="true"`.
**Action:** Always audit `public/site.html` for non-semantic interactive elements and apply the `role="button"` + `tabindex="0"` + keyboard listener pattern. Use `aria-label` to provide screen reader context for repeated interactive rows.
