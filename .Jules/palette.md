## 2025-03-13 - Accordion and Mobile Drawer Accessibility
**Learning:** Raw HTML landing pages with custom interactive accordion containers require `role="button"`, `tabindex="0"`, `aria-expanded` attributes, and `Enter`/`Space` key handlers to be usable with screen readers and keyboard navigation. Additionally, converting nested `<button>` elements inside clickable containers to non-interactive decorative `<span>`s prevents nested interactive control accessibility failures, and using `visibility: hidden` on off-screen mobile drawers removes closed drawer links from the keyboard tab order.
**Action:** When working on HTML-based landing pages with custom interactive components, always ensure focus-visible styles, proper ARIA states, keydown handlers, and off-screen visibility hiding are included.
