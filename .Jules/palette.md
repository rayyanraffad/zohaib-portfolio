## 2025-05-18 - Accessible Accordions and Nested Interactive Controls
**Learning:** In raw HTML or custom interactive row containers (like `.case-row`), using a nested `<button>` inside an interactive container creates invalid nesting and poor screen reader behavior. Furthermore, expanding containers must maintain `aria-expanded` attributes, handle keyboard triggers (`Enter` and `Space`), and ignore clicks originating within open detail blocks so text selection doesn't collapse the container.
**Action:** Convert nested `<button>`s inside custom clickable card/row containers to non-interactive decorative elements (`<span aria-hidden="true">`), make the outer container keyboard-focusable with `role="button"` and `tabindex="0"`, update `aria-expanded` dynamically, and guard click handlers against internal detail clicks.
