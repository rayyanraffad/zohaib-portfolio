## 2025-05-18 - [Accessible Custom Interactive Containers & Mobile Drawer Navigation]
**Learning:** In highly stylized single-page websites, interactive rows or accordion items are often designed as clickable containers with nested action buttons. This triggers nested interactive controls accessibility violations under WCAG (which can confuse screen readers). Additionally, off-screen drawers using only CSS `transform: translateX(100%)` remain interactable and in the keyboard tab order while hidden.
**Action:** Convert nested `<button>` or `<a>` tags within a clickable container (like a `.case-row`) into non-interactive elements (e.g., `<span>`) with `aria-hidden="true"`, ensuring the container itself functions as the sole interactive element with full ARIA attributes (`role="button"`, `tabindex="0"`, `aria-expanded`). Use CSS `visibility: hidden` and `visibility: visible` paired with transition property on the mobile nav drawer to cleanly manage tab-index access when the drawer is off-screen.
