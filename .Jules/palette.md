## 2025-09-26 - Accessible Accordions and Drawer Tab Order in Raw HTML Landing Pages
**Learning:** In raw HTML single-page applications, off-screen mobile navigation drawers translated via CSS (`transform: translateX(100%)`) retain focusable links in the document tab order unless `visibility: hidden` is applied. Furthermore, expandable accordion rows implemented as clickable containers fail WCAG when containing nested `<button>` elements, lacking keyboard handling (`Enter`/`Space`), `role="button"`, and `aria-expanded` states.
**Action:** Always couple CSS drawer slide transitions with `visibility: hidden`/`visible` and `aria-expanded` attributes. For custom card/row accordions, convert inner expand indicator buttons to non-interactive decorative `<span>`s with `aria-hidden="true"`, make the parent row focusable (`tabindex="0"`, `role="button"`), handle keyboard toggle events, and check event targets to prevent text selection from collapsing the container.
